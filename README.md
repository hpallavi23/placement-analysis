# NXTSTEP — Your Next Move, Mapped.

**Academic Project Title:** AI-Based Personalized Placement Readiness & Opportunity Analysis System

NXTSTEP is a student-focused career-readiness prototype designed to help students assess their placement readiness, identify skill gaps, explore personalized learning roadmaps, and understand their alignment with sample placement opportunities.

## Features

- **Placement Readiness Assessment:** Estimates readiness using transparent, rule-based calculations.
- **Skill Gap Analysis:** Identifies strengths and skills that need improvement for a selected target role.
- **Personalized Learning Roadmap:** Suggests a structured four-week improvement plan.
- **Opportunity Matching:** Compares a student's profile against sample placement opportunities and displays matching skills, missing skills, eligibility information, and match explanations.

## Technology Stack

- HTML
- CSS
- JavaScript

## Getting Started

Open the deployed NXTSTEP website through the GitHub Pages link in the repository settings.

To run locally:

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

## Current Scope and Limitations

This version is an interactive prototype. It uses sample student profiles, sample opportunities, and rule-based calculations.

The readiness score and opportunity match percentages are illustrative estimates, not validated predictions of placement success. The current prototype does not claim to use a trained machine-learning model, a live job listing API, user authentication, or a connected database.

## Future Scope

Planned extensions may include a backend using FastAPI, persistent storage using MySQL, and an appropriately evaluated machine-learning component.

## Academic Context

Developed as a BTech major-project prototype to explore personalized placement readiness and opportunity analysis.
